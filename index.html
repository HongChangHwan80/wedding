🎵 베트남 웨딩 BGM 설정

베트남 결혼식에서 가장 사랑받는 대표 웨딩송

1. 기본 내장 웨딩 멜로디 선택 (클릭 시 즉시 변경)

2. 원곡 MP3 파일 직접 넣기

소장하신 원곡 MP3 파일을 GitHub 저장소에 bgm.mp3 이름으로 함께 올리시면 자동으로 원곡이 재생됩니다. 지금 바로 아래 버튼으로 내 폰/PC의 MP3를 테스트해 보실 수도 있습니다.

💡 웨딩촬영 후 사진/영상 교체 가이드

1. 폴더 구조 (GitHub 저장소)

📁 wedding-invitation/
 ├── index.html (현재 이 파일)
 ├── bgm.mp3 (베트남 결혼 음악 파일)
 ├── 📁 images/
 │    ├── main.jpg (메인 대표 웨딩사진)
 │    ├── photo1.jpg ~ photo9.jpg (갤러리 사진 9장)
 └── 📁 videos/
      ├── clip1.mp4 (짧은 영상 1)
      └── clip2.mp4 (짧은 영상 2)

2. 사진만 바꾸는 가장 쉬운 방법

코드 안에서 TODO: 로 검색하시면 메인 사진, 짧은 영상 2곳, 그리고 하단 스크립트의 GALLERY_PHOTOS 배열이 나옵니다. 여기에 준비된 사진 경로만 넣으시면 즉시 완성됩니다!

3. 하객에게 공유하기 전 팁

현재 화면에 보이는 '메인 사진/영상 테스트' 버튼들은 신랑신부님이 사진을 미리 넣어보실 수 있도록 만든 기능입니다. 실제 배포 시에는 하단의 '사진 테스트 버튼 숨기기'를 누르거나 코드 내 SHOW_PREVIEW_CONTROLS = false 로 바꾸시면 깔끔하게 사라집니다.

복사되었습니다.
